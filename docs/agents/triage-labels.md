# Triage-метки

Skills оперируют пятью стандартными ролями triage. Этот файл сопоставляет роли со строками, которые пишутся в строку `Status:` файла задачи в `.scratch/`.

| Метка в mattpocock/skills | Метка у нас       | Значение                                         |
| ------------------------- | ----------------- | ------------------------------------------------ |
| `needs-triage`            | `needs-triage`    | Мейнтейнеру нужно оценить задачу                 |
| `needs-info`              | `needs-info`      | Ждём от автора дополнительную информацию         |
| `ready-for-agent`         | `ready-for-agent` | Полностью описана, готова для автономного агента |
| `ready-for-human`         | `ready-for-human` | Нужна реализация человеком                       |
| `wontfix`                 | `wontfix`         | Делать не будем                                  |

Когда skill упоминает роль (например, «поставь метку готовности для агента»), используй соответствующую строку из этой таблицы.

Если используете другие названия, поправьте правую колонку.
